## Structure

Each topic folder follows the same layout:

```
NN_Topic/
├─ src/
│  ├─ pattern_or_category/
|  |  ├─ ProblemName.java
|  |  ├─ ...
|  ├─ ...
└─ notes.md
```

`notes.md` covers the topic's theory (overview, complexity, key techniques) followed by a "Problems by Pattern" section grouping solved problems under the technique they demonstrate.
